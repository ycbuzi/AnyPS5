# libSceVideoRecordingP technical debt

### Silent stubs

- [libSceVideoRecordingP](../../../core/libs/prx/libSceVideoRecordingP/Export.cpp) has no recorder: `sceVideoRecordingQueryMemSize` and `sceVideoRecordingOpen` return `SCE_VIDEO_RECORDING_ERROR_UNSUPPORTED` (0x80A80008), `sceVideoRecordingGetStatus` reports `SCE_VIDEO_RECORDING_STATUS_NONE` (0), and `sceVideoRecordingStart`, `sceVideoRecordingStop` and `sceVideoRecordingClose` throw, as no recording is ever open. `sceVideoRecordingSetInfo` keeps the info only for `sceVideoRecordingGetInfo`
